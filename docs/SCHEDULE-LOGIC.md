# Schedule Logic

## Core Idea

The working day is organized around three clear placement zones:

1. Planning and sprint launch from 09:00 to 10:00.
2. Work-task slots from 10:00 to 14:00.
3. Personal-task slots from 14:00 to 16:00.

The visual rule is simple: personal-task slots use the green development tone, and work-task slots use the red work tone.

The lower widget area is a notes/checklist block instead of a weekly-task list. It contains four fixed checklist notes, a list of temporary notes, and one permanent "new task" row that never disappears.

## Base Day

```text
09:00-10:00  Plan the day + launch the sprint
10:00-14:00  Work tasks, red slots
14:00-16:00  Personal tasks, green slots
16:00        Workday closed
```

## Notes Block

Fixed checklist notes:

- Armory, 30 minutes
- Skill, 30 minutes
- Morning plan
- Shorts

Each fixed note has a done/not-done checkbox, and that status is scoped to the selected day. If Armory was done yesterday, it must be available again today. Temporary notes are added through the permanent "new task" row. New temporary notes start unchecked. If a temporary note is checked, it stays visible and struck through for that day. If it is not checked, it carries forward into the next day. Temporary notes should look slightly different from fixed notes.

## Planning and Sprint Launch

Goal: make the day operational before deep work starts.

This slot includes:

- decide the main day focus
- prepare or confirm the Codex sprint
- launch the sprint
- check that sync and working context are ready

## Personal Slots

Goal: keep 14:00-16:00 reserved for personal tasks.

These slots are taskable and should visually read as green development slots.

## Work Slots

Goal: keep 10:00-14:00 reserved for work tasks.

These slots are taskable and should visually read as red work slots.

## Daily Cycle

```text
09:00:
- plan the day
- launch the sprint

10:00-14:00:
- handle work tasks

14:00-16:00:
- handle personal tasks
```
